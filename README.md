# Python Programming Coursework

Completed Python programming coursework from the Data Science master's programme at Dalarna University, Sweden.

## Running an exercise

Use Python 3 and open a terminal in the folder containing the selected script. For example, from `python-lab2-assignment/`:

```bash
python bmi_calculator.py
```

Use `python3` if that is your system's Python 3 command. Interactive programs prompt for input in the terminal. Exercises that read or write files may rely on the current working directory, so run them from their own folders.

This collection has no single application entry point or shared installation process. Consult the workshop READMEs and individual scripts for exercise-specific requirements. The standalone applications document their own setup.
